# SCOPE (MVP)

## 이번 MVP 포함 범위
- **watchlist**: 관심그룹/관심종목 등록/조회/정렬(기본)
- **monitor**: 관심종목 핵심 지표 모니터 패널
- **chart**: `lightweight-charts` 기반 기본 시계열 차트
- **news**: 종목별 뉴스 요약 목록(Mock)
- **memo**: 종목/그룹 단위 메모
- **rotation lock**: 5초 단위 자동 로테이션 + LOCK 기능
- **pin**: 중요 종목 PIN 고정 노출

## 이번 MVP 제외 범위
- 실거래/주문 기능
- 실제 브로커 인증/연동
- 고급 백테스트, 포트폴리오 최적화
- ETF/그래프/패시브 심화 분석(후속 버전)

## 데이터 정책 (초기)
- 시장/뉴스 데이터는 Mock으로 시작
- 데이터 형태(스키마)는 실데이터 전환을 고려해 정의
- 실데이터 도입 시 Adapter 교체를 원칙으로 함

## 산출물 기준
- Web MVP 구현에 필요한 최소 기능 흐름을 우선
- 기능 완성도 > 기술 확장성(단, Adapter 분리는 유지)
