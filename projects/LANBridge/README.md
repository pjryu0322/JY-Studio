# LANBridge - 자료 공유 P2P 앱

**LANBridge**는 로컬 WiFi 네트워크에서 WebRTC 기반 P2P 연결을 통해 실시간 채팅과 자료 공유를 지원하는 애플리케이션입니다.

## 🎯 핵심 특징

- ✅ **P2P 연결**: 중앙 서버 없이 직접 1:1 P2P 연결
- ✅ **실시간 채팅**: P2P DataChannel을 통한 텍스트 메시지
- ✅ **화면 공유**: 공유자와 참여자 간 양방향 화면 공유
- ✅ **원클릭 시작**: start.bat 더블클릭으로 즉시 실행
- ✅ **자동 LAN 주소**: 런처에서 LAN IP 자동 표시
- ✅ **쉬운 배포**: ZIP 압축본으로 다른 PC에 전달 가능
- 🔐 **HTTPS 지원**: LAN 내 다른 PC와 화면 공유 (자체 서명 인증서)
- 📦 **간단한 설치**: Node.js만 필요 (npm install 자동 실행)

## 🚀 빠른 시작 (Windows/Mac/Linux)

### 📋 요구사항
- **Node.js v16+** ([다운로드](https://nodejs.org/ko/))
- 최신 브라우저 (Chrome, Edge, Firefox 등)
- 같은 WiFi 네트워크에 연결된 PC
- **화면 공유 사용 시**: HTTPS 또는 localhost (보안 컨텍스트 필수)

> ⚠️ **화면 공유 기능을 사용하려면 HTTPS 설정이 필요합니다.**  
> 📖 자세한 설정 방법: [HTTPS-SETUP.md](HTTPS-SETUP.md) 참고

### 1단계: Node.js 설치

1. [nodejs.org](https://nodejs.org/ko/) 방문
2. **LTS 버전** 다운로드 및 설치
3. 설치 완료 후 **컴퓨터 재부팅** (또는 터미널 재시작)

### 2단계: LANBridge 시작 (원클릭 방식)

1. **start.bat 파일 더블클릭**
2. 첫 실행 시: `npm install` 자동으로 의존성 설치 (1-2분 소요)
3. 런처 UI가 브라우저에 자동 열림 (`http://localhost:9100`)
4. **"서버 시작" 버튼 클릭**
5. LAN 주소 표시 (예: `http://192.168.0.100:3000`)

### 3단계: 공유자와 참여자 연결

#### 공유자 (공유자 역할) - PC-A

1. 런처에서 표시된 **LAN 주소** 복사 (예: `192.168.0.100:3000`)
2. 브라우저에서 자동 열린 LAN 주소 접속
3. **"공유자" 선택**
4. 방 제목 입력 후 **"방 개설" 버튼** 클릭
5. 럼 코드 또는 방 링크를 참여자에게 공유

#### 참여자 (참여자 역할) - PC-B

1. 공유자가 보낸 **LAN 주소** 브라우저에 입력
2. **"참여자" 선택**
3. 활성 방 목록에서 공유자의 방 선택 후 **"입장"** 
4. 연결 완료! 이제 채팅 가능

### 4단계: 다른 PC에 전달하기

**ZIP 패키지로 압축해 전달:**

1. LANBridge 폴더 전체 선택
2. **우클릭 → 압축** (또는 7-Zip/WinRAR 사용)
3. `LANBridge-portable.zip` 생성
4. 메신저/이메일로 다른 사용자에게 전달
5. 받은 쪽에서:
   - ZIP 압축 해제
   - **start.bat 더블클릭**
   - 그 이상 설정 불필요!

**💡 팁:**
- node_modules 폴더는 포함하지 않고 압축해도 되며, start.bat 첫실행 시 자동으로 설치됩니다
- ZIP 크기: ~1MB 정도 (node_modules 제외 시)

| | PC-A | PC-B |
|---|---|---|
| 역할 | 공유자 (화면 공유 시작) | 참여자 (수신자) |
| 네트워크 | 동일 LAN | 동일 LAN |
| 주소 예시 | `http://192.168.1.10:5500` | `http://192.168.1.20:5500` |

#### 연결 절차 (마법사 모드 - 권장)

**두 PC 모두:**

1. 브라우저에서 LANBridge 열기
   - PC-A: `http://192.168.1.10:5500`
   - PC-B: `http://192.168.1.20:5500`

2. **"🚀 빠른 연결 (마법사)"** 버튼 클릭

3. **역할 선택 화면에서 자신의 역할 선택**
   - 🎬 **PC-A (공유자)** 선택 → 화면을 보여줄 쪽이면 이 버튼
   - 👁️ **PC-B (참여자)** 선택 → 상대 화면을 받을 쪽이면 이 버튼

**PC-A (공유자)에서:**

1. 🎬 **PC-A (공유자)** 선택
2. "1️⃣ 오퍼 생성" 클릭
3. "✂️ 클립보드에 복사" 클릭 (또는 데이터 복사)
4. **PC-B에 메모/메일/USB 등으로 데이터 전달**
5. PC-B에서 받은 응답 데이터를 마법사의 입력창에 붙여넣기
6. "📌 상대 데이터 설정" 클릭
7. "🎉 마법사 닫기" → **연결 완료!**

**PC-B (참여자)에서:**

1. 👁️ **PC-B (참여자)** 선택
2. **PC-A에서 받은 오퍼 데이터를 입력창에 붙여넣기**
3. "📌 상대 오퍼 설정" 클릭
4. "1️⃣ 응답 생성" 클릭
5. "✂️ 클립보드에 복사" 클릭 (또는 데이터 복사)
6. **PC-A에 메모/메일/USB 등으로 데이터 전달**
7. "✅ 복사 완료, 완료" 클릭
8. "🎉 마법사 닫기" → **연결 완료!**

#### 연결 절차 (수동 시그널링)

**고급 모드: 역할 선택 없이 수동으로 진행하려면 "⚙️ 고급: 수동 시그널링" 항목을 펼치세요.**

**PC-A (공유자)에서:**

1. 브라우저에서 `http://[PC-A의 IP]:5500` 열기
   - 예: `http://192.168.1.10:5500`
   
2. 상단 우측의 "이름(선택)" 입력란에 본인 이름 입력 (선택사항)
   - 기본값: `게스트-xxxx` 형식

3. 좌측 아래 **"오퍼 생성"** 버튼 클릭
   - 하단 로그 패널에 `"오퍼 생성 완료"` 메시지 출력
   
4. **시그널링 데이터 박스에서 JSON 복사**
   - 좌측 하단 "시그널링 데이터" 박스에 JSON 형식의 `offer` 데이터가 표시됨
   - **"복사" 버튼 클릭 또는 전체 선택 후 복사 (Ctrl+A, Ctrl+C)**

5. **PC-B에 전달**
   - 복사한 데이터를 PC-B에 **메모, 메일, USB, 또는 네트워크 공유** 등으로 전달
   - *(MVP: 보안/암호화 없으므로, 신뢰할 수 있는 네트워크에서만 사용)*

---

**PC-B (참여자)에서:**

1. 브라우저에서 `http://[PC-B의 IP]:5500` 열기
   - 예: `http://192.168.1.20:5500`

2. 상단 우측의 "이름(선택)" 입력란에 본인 이름 입력

3. 좌측 아래 "시그널링 데이터" 박스에 **PC-A에서 받은 Offer JSON을 붙여넣기 (Ctrl+V)**

4. **"오퍼 붙여넣기"** 버튼 클릭
   - `"상대 오퍼 설정 완료"` 메시지 출력
   - **"응답 생성"** 버튼 활성화

5. **"응답 생성"** 버튼 클릭
   - 새로운 JSON 형식의 `answer` 데이터가 시그널링 박스에 표시됨
   - **"복사" 버튼 클릭 또는 전체 선택 후 복사 (Ctrl+A, Ctrl+C)**

6. **Answer를 PC-A에 전달**
   - 복사한 Answer 데이터를 PC-A로 전달

---

**PC-A로 돌아가서:**

1. 시그널링 박스에 **PC-B에서 받은 Answer JSON을 붙여넣기 (Ctrl+V)**

2. **"응답 붙여넣기"** 버튼 클릭
   - `"상대 응답 설정 완료"` 메시지 출력
   - 상단의 연결 상태가 **"연결 중"** → **"연결됨"** 로 변경되어야 함 (2-3초)
   - 상태 표시등: 🔴 (연결 끊김) → 🟡 (연결 중) → 🟢 (연결됨)

3. 연결 성공! ✅
   - 양쪽 "채팅" 탭에 `"✓ 상대와 연결됨"` 시스템 메시지 표시
   - 채팅 입력창 활성화, 파일 업로드 활성화

#### 연결 완료 후 사용법

**화면 공유 (PC-A → PC-B)**

1. **"화면 공유 시작"** 버튼 클릭
   - 운영체제 화면 공유 권한 요청 창 출현
   - 공유할 화면/모니터 선택 후 **"Share"** 클릭
   - PC-B의 좌측 큰 화면에 PC-A의 화면이 실시간으로 표시됨

2. 화면 공유 중지: **"화면 공유 중지"** 버튼 클릭

**채팅**

1. 우측 패널의 **"채팅"** 탭 확인
2. 하단 입력창에 메시지 입력
3. **"전송"** 버튼 클릭 또는 **Enter** 키
4. 메시지가 양쪽에 표시됨
   - 로컬 메시지: 녹색 배경
   - 원격 메시지: 회색 배경

**파일 공유**

1. 우측 패널의 **"파일"** 탭으로 이동
2. 파일을 드래그&드롭하거나, **"파일을 끌어놓거나 클릭하여 선택"** 영역에서 파일 선택
3. 상대방 PC에서:
   - 수신 파일 리스트에 파일이 나타남
   - **"받기"** 버튼으로 수신 시작
   - 진행률 표시 확인
   - 100% 완료되면 **"저장"** 버튼으로 로컬 다운로드## 📂 프로젝트 구조

## 🏗️ 시스템 아키텍처

```
공유자 PC (PC-A)
├─ launcher.js (포트 9100) → 런처 제어 UI
├─ signal-server.js (포트 3000) → 신호 서버 + SDP 중계
└─ index.html (브라우저) → 앱 UI / 채팅

참여자 PC (PC-B)
└─ 브라우저에서 공유자의 LAN 주소(3000)로 접속
   └─ index.html → 앱 UI / 채팅

[P2P WebRTC 연결]
PC-A ←→ PC-B (직접 연결, 신호 서버는 SDP만 중계)
```

## 🔄 동작 흐름

### 1. 서버 시작
```
사용자는 start.bat 더블클릭
    ↓
launcher.js 시작 (포트 9100)
    ↓
브라우저 자동 열림 (http://localhost:9100)
    ↓
"서버 시작" 버튼 → signal-server.js 자동 시작 (포트 3000)
    ↓
런처에서 LAN IP 주소 표시
```

### 2. 방 개설 (공유자)
```
브라우저에서 LAN:3000 접속
    ↓
"공유자" 역할 선택
    ↓
방 제목 입력 → "방 개설"
    ↓
방이 서버에 생성됨 + Offer 자동 생성
```

### 3. 방 입장 (참여자)
```
참여자가 같은 LAN:3000에 접속
    ↓
"참여자" 역할 선택
    ↓
활성 방 목록에서 공유자의 방 선택
    ↓
Answer 자동 생성 + P2P 연결 성공
```

### 4. 채팅 (P2P)
```
공유자 ←→ 참여자 (P2P WebRTC DataChannel)
텍스트 메시지 즉시 전달 (신호 서버 거치지 않음)
                       
```

## 📌 문제 해결

### 🔴 "서버 시작 버튼을 눌러도 반응이 없음"

1. **Node.js 설치 확인**
   ```powershell
   node --version   # v16 이상이어야 함
   ```

2. **포트 3000이 사용 중인지 확인**
   ```powershell
   netstat -ano | findstr :3000
   # 만약 다른 프로세스가 포트를 사용 중이면:
   # taskkill /PID [PID] /F
   ```

3. **브라우저 콘솔에서 에러 확인**
   - F12 → Console 탭 열기
   - 빨간 에러 메시지 확인

### 🔴 "참여자가 방 목록을 볼 수 없음"

1. **같은 WiFi 네트워크 확인**
   ```powershell
   # 공유자 PC에서:
   ipconfig
   # IPv4 주소 확인 (예: 192.168.0.x)
   
   # 참여자 PC에서 공유자 PC로 ping 가능한지 확인:
   ping 192.168.0.100  # 공유자 IP
   ```

2. **런처에서 표시된 주소가 올바른지 확인**
   - 예: `http://192.168.0.100:3000`
   - 로컬 주소가 아닌 **LAN IP**인지 확인

3. **방화벽 확인** (Windows Defender)
   - Settings → Privacy & Security → Windows Security
   - Firewall & network protection → Allow an app through firewall
   - `node.exe` 허용 확인

### 🔴 "P2P 연결에 실패함"

1. **신호 서버 상태 확인**
   - 런처에서 "✅ 서버 실행 중" 표시되는지 확인
   - 콘솔에 에러 메시지 없는지 확인

2. **WebRTC ICE 후보 수집 대기**
   - ICE gathering에 2-3초 소요될 수 있음
   - 잠시 기다린 후 "연결" 버튼 다시 클릭

3. **브라우저 콘솔 에러 메시지 확인**
   ```javascript
   // "Failed to create offer", "RTCError: Failed to set remote answer"
   // 등의 메시지 확인
   ```

각 새로운 PC에 배포하기 전 체크:

- [ ] LANBridge 폴더를 ZIP으로 압축
- [ ] ZIP 파일을 상대방에게 전달
- [ ] 상대방이 ZIP 압축 해제
- [ ] **start.bat 더블클릭** (node_modules 자동 설치)
- [ ] 런처 UI 열림 (localhost:9100)
- [ ] "서버 시작" 클릭 → "✅ 서버 실행 중" 표시
- [ ] LAN 주소 표시 (예: `192.168.0.x:3000`)
- [ ] 브라우저에서 LAN 주소 접속 가능
- [ ] 방 개설/참여 테스트
- [ ] 채팅 전송/수신 확인
