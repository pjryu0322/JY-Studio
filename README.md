# JY-Studio

Monorepo for JY-Studio applications. All runnable apps live under `projects/`.

## Projects

| Project | Description |
|---------|-------------|
| [LANBridge](projects/LANBridge/README.md) | WebRTC-based chat/file sharing on the local network (Electron). |
| [krx-monitor](projects/krx-monitor/README.md) | KRX watchlist monitor with charts and rotation (Next.js + NestJS). |

## How to run

See each project’s README for prerequisites, local run, build, and test:

- [LANBridge → Local run](projects/LANBridge/README.md#local-run)
- [krx-monitor → Local run](projects/krx-monitor/README.md#local-run)

## Contributing

- **Branch:** Create a feature branch from `main`; do not commit directly to `main`.
- **PR:** Open a PR for review; keep changes small and scoped.
- **Commit:** Use small, atomic commits with clear messages.
